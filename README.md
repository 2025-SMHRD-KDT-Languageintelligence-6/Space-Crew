**BERT 및 GPT 기술을 활용한 전자정부표준프레임워크 기반 프로젝트관리시스템**


1. 표준 플랫폼 기반 시스템 아키텍처 설계  
  확장성을 고려한 eGovFrame 4.2(Spring) 기반의 안정적인 백엔드 구조 설계  
  공통 컴포넌트(MyBatis)를 활용한 로그인, 권한 관리 등 로그인 모듈 구축  
  공통 컴포넌트와 인터셉터(Interceptor), 필터를 활용한 보안 및 세션 관리 최적화  

2. 프로젝트 통합 관리 기능 전반 구현  
대시보드(Dashboard) : 경영 정보 통합 관리를 위한 실시간 핵심 지표 시각화  
배정 관리(Assignment) : 사원별 가동률 자동 계산 알고리즘 및 프로젝트 배정 최적화 로직 설계(BERT)  
보고서 자동화 : 주간 보고서 및 회의록 데이터의 정형화 및 관리 프로세스 구축(OpenAI API)  

3. 멀티 포맷 문서 파싱 엔진 (Python Integration)  
HWP(OLE), DOCX, TXT 등 다양한 문서 파일의 바이너리를 직접 분석하고 텍스트를 추출하는 Python 기반 파이프라인 구현  
외부 AI 모듈과의 데이터 동기화를 위한 REST API 규격 설계 및 데이터 전처리(Pre-processing)  

4. 데이터베이스 모델링  
MariaDB 관계형 모델링 : 프로젝트 생명주기(Lifecycle) 전반을 포괄하는 테이블 설계 및 데이터 무결성 확보를 위한 DB 스키마 최적화
